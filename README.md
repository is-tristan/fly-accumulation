# Fly Accumulation

Next.js + Sanity site for Fly Accumulation, based on the R4 Advertising layout.

## Getting Started

1. Copy `.env.example` to `.env.local` and fill in Sanity project values.
2. Install dependencies and run the app:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Sanity Studio is available at `/studio` once env vars are set.
